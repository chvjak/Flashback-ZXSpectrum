# Flashback ZX

Flashback (1992) on the ZX Spectrum +3: level 1, the jungle, on a 720K +3
disk, played in the browser on an emulated +3 -- https://chvjak.github.io/Flashback-ZXSpectrum/

This repository holds the built page only:

- `index.html` -- the page, with the emulator's JavaScript in it;
- `plus3.wasm`, `plus3-0.rom` ... `plus3-3.rom` -- the +3 (its source and
  licences in `emulator/`; the ROMs (c) Amstrad, who allow their
  distribution with emulators);
- `flashback-l1.dsk` -- the level's disk, built from the freely
  distributed 1993 PC demo of Flashback.
